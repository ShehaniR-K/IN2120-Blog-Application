\# IN2120 Blog Application



A blog application developed for the IN2120 Web Programming take-home assignment.



\## Technologies Used



\- HTML

\- CSS

\- JavaScript

\- PHP

\- MySQL



\## Planned Features



\- User registration

\- User login and logout

\- Create blog posts

\- View all blog posts

\- View a single blog post

\- Edit own blog posts

\- Delete own blog posts

\- User authorization

\- Responsive user interface



\## Current Status



Initial project structure created.
